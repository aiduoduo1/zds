# 维修表单校验与显示设计

## 目标

调整 `RepairActivity` 的草稿与提交校验、输入长度以及维修结果显示，不改变维修接口字段和值。

## 规则

- 保存草稿只要求已扫描并加载维修记录，维修结果、不良原因、维修人、维修说明均允许部分填写。
- 正式提交时，维修结果、不良原因、维修人和维修说明全部必填。
- 维修说明最多输入 1000 个字符，hint 使用更浅的提示色。
- 维修人最多输入 10 个字符。
- 维修结果内部保存并提交字典 `value`，页面和选择弹窗显示对应的 `label`。
- 后端已有维修结果回显时，通过字典 `value` 查找 `label`；字典晚于记录返回时重新刷新显示。

## 范围

只修改 `RepairActivity` 及其布局，不改变 ViewModel、Repository、接口、扫码、拍照和提交成功后的页面清理流程。

## 验证

- 单元测试覆盖维修结果 value 到 label 的映射及无匹配时的回退。
- 执行 app Debug 单元测试和 Kotlin 编译。
