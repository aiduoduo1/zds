# 单个调试核对项与提交校验同步设计

## 目标

让 `SingleDebugActivity` 的调试表核对项解析、输入规则和提交前校验与 `DebugTaskExecuteActivity` 保持一致，同时保留单个调试现有接口和单提交按钮。

## 方案

- 直接复用 `DebugTaskInputRules` 识别确认、数值、文本和拍照采集类型，并使用相同的文本长度与匹配规则。
- 直接复用 `DebugTaskSubmitRules` 判断需要触发不良现象上报的失败项。
- 文本内容与提示内容不一致时仍在前端标红，但不计入 footer 不良数量，也不触发不良现象选择。
- 未完成项仍只统计不可跳过项，定位第一条未完成项时同样排除可跳过项。
- 单个调试继续调用原有提交接口，不新增保存草稿按钮，不改变扫码、拍照及提交成功后的清空流程。

## 验证

- 单元测试覆盖文本失败不属于可上报不良、确认或数值失败属于可上报不良。
- 编译 `app` Debug Kotlin，并执行现有 Debug 单元测试。
